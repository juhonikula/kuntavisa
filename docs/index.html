Kuntavisa

Napauta kartalta kysyttyä kuntaa. Kolme yritystä per kunta: vihreä = ensimmäisellä, keltainen = 2. tai 3. yrityksellä, punainen = ei löytynyt.

Kirjoita kuntien nimiä missä järjestyksessä tahansa. Oikea nimi hyväksytään heti, kirjainkoolla ja ä/ö-pisteillä ei ole väliä.
